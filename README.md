# T.I.D.E. BOT Research Website

An interactive research and robotics website for **T.I.D.E. BOT (Trash Inspection and Debris Extraction Bot)**, an Arduino-based semi-autonomous surface vehicle designed for shoreline floating waste collection.

## About the Project

**T.I.D.E. BOT** is a student-developed robotics research project focused on designing and evaluating a surface vehicle capable of detecting and collecting floating solid waste near the shoreline of **Pachoca, Calapan City, Oriental Mindoro**.

The website presents the research project through a combination of **technical documentation, interactive robotics simulations, system visualizations, and researcher profiles**.

## Robotics System

The prototype is based on:

* **Arduino Uno R3**
* **L298N Dual H-Bridge Motor Driver**
* **2× HC-SR04 Ultrasonic Sensors**
* **2× DC Geared Motors**
* **Boat Propellers**
* **Rechargeable Battery**
* **Bluetooth Module**
* **Integrated Nylon Mesh Collection Net**
* **Waterproof Electronics Enclosure**
* **Lightweight Floating Hull**
* **Two 1.5 L Plastic Bottles for Buoyancy**
* Waterproof/lightweight structural materials

## Simulation

The interactive simulation demonstrates the intended behavior of the T.I.D.E. BOT.

The robot can:

1. Detect nearby objects using virtual ultrasonic sensors.
2. Identify floating debris as a collection target.
3. Navigate toward collectible debris.
4. Collect debris when it enters the collection zone.
5. Detect obstacles.
6. Reverse when both sides are blocked or the robot becomes stuck.
7. Rotate while searching for an open path or collectible debris.
8. Continue navigation after finding a suitable path.

The simulation is an **educational representation of the proposed system** and does not represent actual field-test measurements.

## Purpose

This website serves as a digital presentation of the T.I.D.E. BOT research project. It is designed to make the technical concepts behind the prototype easier to understand while providing an interactive demonstration of how the proposed robotic system operates.

## Disclaimer

The interactive simulation is a **conceptual demonstration** of the T.I.D.E. BOT's intended behavior. Actual performance values such as collection efficiency, operating time, load-bearing capacity, and navigation performance must be established through experimental testing and should not be inferred from the website simulation.
